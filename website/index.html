FAQ

Keep the answers short too.

Do I need Python or Git?

The development build currently uses them. The consumer Windows package is being prepared so normal users will install and open the app like any other program.

Does it require a GPU?

No. The product supports CPU generation and can use compatible GPU acceleration when the installed runtime can actually access it.

Does it download every model?

No. The app shows what is installed and what is available. Large model downloads only start after an explicit action.

Who provides the current speech models?

The current engine uses open-source Chatterbox models. Full attribution, source notices and license information are kept in the application's About section and repository notices.
